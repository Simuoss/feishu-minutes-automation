# 任务：扫描截图中的敏感信息

你将收到一批会议录屏截图，以及一份清单（编号与图片顺序一致）。请逐张判断画面上是否出现**可读的敏感信息**。

## 什么算敏感

必须标出的：

- API 密钥、access token、secret、password、私钥、连接串里的口令
- 身份证号、银行卡号、完整手机号、个人住址
- 明显属于私人聊天/私信窗口且含身份信息的内容
- 其它一旦泄露会造成账号或人身安全风险的凭据

不要标为敏感的：

- 普通代码、报错栈、命令行输出（除非其中夹着密钥）
- 公开文档、网页标题、课程内容
- 已被涂抹/模糊到无法辨认的区域
- 看不清、分辨率太低以至于无法确认是否为密钥的片段（宁可不标，也不要瞎猜大片区域）

## 坐标约定

对每块敏感区域给出**归一化坐标**（相对整张图宽高，原点在左上角）：

- `x1, y1`：敏感区域左上角，取值 `[0, 1]`
- `x2, y2`：敏感区域右下角，取值 `[0, 1]`
- 必须满足 `x1 < x2` 且 `y1 < y2`
- 框要紧贴敏感文字，可略微外扩（约 2%~5%），但不要整屏乱框
- 同一张图可有多块区域

## 输出格式

只输出一个 JSON 对象，不要其它说明文字，不要代码围栏：

```
{
  "figures": [
    {
      "figure_id": "fig-01",
      "sensitive": false,
      "regions": []
    },
    {
      "figure_id": "fig-02",
      "sensitive": true,
      "regions": [
        {
          "label": "API密钥",
          "x1": 0.12,
          "y1": 0.40,
          "x2": 0.78,
          "y2": 0.48
        }
      ]
    }
  ]
}
```

要求：

- `figures` 必须覆盖清单里的**每一张**图，`figure_id` 与清单一致
- `sensitive` 为 `true` 时 `regions` 至少有一项；为 `false` 时 `regions` 必须为空数组
- `label` 用简短中文说明敏感类型即可
